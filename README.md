## 隱私
公開 GitHub 只包含程式、行程與公開優惠資料。訂單碼、付款資訊、日記、照片、記帳等皆儲存在使用裝置的 IndexedDB。

私人訂房資料可透過另外提供的 JSON 檔匯入；**請勿把 PRIVATE IMPORT JSON 上傳 GitHub**。

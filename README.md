# Japan Road Trip 2026 — PWA V2 Beta

新增：美化首頁、日幣換算、信用卡攻略、必買清單、旅行記帳、旅行日記與照片、回憶錄列印、私人住宿資料、備份/還原、景點導讀。

## 隱私
公開 GitHub 只包含程式、行程與公開優惠資料。訂單碼、付款資訊、日記、照片、記帳等皆儲存在使用裝置的 IndexedDB。

私人訂房資料可透過另外提供的 JSON 檔匯入；**請勿把 PRIVATE IMPORT JSON 上傳 GitHub**。


## V2.1
- 內建 6 間住宿封面照，離線可看；App 內手動上傳的封面仍會優先顯示。
- GitHub 公開資料新增：訂房平台、金額、付款狀態、免費取消期限、含餐狀況。
- 不公開：訂房號碼、驗證碼、使用哪張信用卡等私人欄位；這些仍存 IndexedDB。


## V2.2｜Cards & Spend
- 信用卡「即時比一比」：情境、日圓金額、海外手續費估算。
- 登錄/自扣資格與 Visa / Mastercard / JCB 卡組織可在 App 本機設定，不寫進 GitHub。
- 日本藥妝/電器情境會依卡組織提示 Visa Select / JCB 優惠。
- 記帳新增付款卡下拉選單、收據照片、分類統計。
- 收據 OCR Beta：使用 Tesseract.js 日文+英文辨識；第一次需網路下載 OCR 模組，辨識結果須人工確認。
- 首頁新增下一個住宿免費取消期限提醒。


## V2.3｜Hotel Image Fix + Memories
- 六間飯店照片直接內嵌於 `data.js`，不再依賴 GitHub `assets/hotels` 資料夾。
- App 內手動更換封面仍優先顯示；新增「恢復內建封面」。
- 必買清單可記錄實買價格，並一鍵加入旅行記帳。
- 旅行日記新增編輯、⭐ 精選、照片/日記統計。
- 回憶錄可預覽列印 PDF，或下載成單一 HTML，內含壓縮照片、花費分類與已購清單。


## V2.4｜LIVE Trip Mode
- 新增「今日旅行模式」：下一站、下一段駕駛、今晚住宿、今日停車、Plan B、全天時間軸集中一頁。
- 行程可在手機上逐項勾選完成，完成狀態只存在本機。
- 旅行模式提供快速新增支出、掃描收據、旅行日記、刷卡比較。
- 底部導覽第二個分頁改成「旅行」，完整行程仍可從旅行模式進入。
- ART HOTEL Narita 新增 BOOKING 卡，但只顯示「已預約／詳細資料待補」，不猜測平台、金額或取消期限。


## V2.5｜Flights + Verified Map Codes
- ART HOTEL Narita 免費取消期限更新為 2026/10/30。
- 新增航班頁：BR196 / BR195、航廈、當地時間、去程48小時選位提醒。
- 可把航班與 BR196 選位提醒下載成 .ics 加入手機行事曆。
- 今日旅行模式 D01 / D10 自動顯示當日航班。
- Map Code 介面統一：所有有 Google Maps 的項目旁都會顯示 Map Code。
- 已核實者顯示可複製代碼；路線、未指定店家或無可靠專用碼者顯示「Map Code：—」，不以猜測值誤導。
- 本版主要 Map Code 以 Mapion 查核（2026/09/04）。
